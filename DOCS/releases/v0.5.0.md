## ORBIT 0.5.0

A major focus, polish, and DJ-ecosystem release: one unified transition store with visible one-click Auto-Mix, Prep for Mix on playlists, a full Genre view across Library and Dashboard, 2026 Spotify compatibility with zero-login public links, cleaner Search & quality matching, bulk folder relocation, richer tag cleanup, and multi-target DJ exports for Rekordbox, Traktor Pro, VirtualDJ, and Serato DJ.

### Focus & Auto-Mixing (#517)
- **One transition store:** Unified `Transitions` table with automatic backfill from legacy playlist and set transition tables, plus a 3-step resolver (playlist override → pair default → Auto) shared across playback, Mix tab, and Transitions.
- **Prep for Mix on playlists:** Every playlist header shows a live readiness badge (e.g. `Ready 42/45`) with a one-click **Prep for Mix** action that analyses missing BPM, beat grids, loudness, and cues while never overwriting hand-set or imported cues.
- **Visible Auto-Mix & Technique dropdown:** A **Mix** button sits right beside **Play**, the queue and Now Playing show clear transition labels (e.g. `Auto · phrase-aligned`), and transition editing uses a single **Technique** dropdown (`Auto`, `Cut`, `Echo-Out`, `Filter Sweep`, `EQ Swap`, `Loop`) with scores/ratings removed from the core UI.
- **Regrouped sidebar & Labs toggle:** Navigation is organized into **Acquire**, **Library & Prep**, and **Play & Mix** (Flow Builder is now **Transitions**). **Sets**, **Workstation**, and **Edit Lab** live behind **Settings → Labs** (kept enabled automatically if you already have saved sets). Edit Lab gains the 4-stem mute/preset rack.

### Genre View (#561)
- **GENRES tree in the Library sidebar:** Collapsible canonical genre tree under **PLAYLISTS** with top-10 + `"N more…"` overflow under `Other`, `Unclassified` last, mono track counts, and persisted collapsed state.
- **Genre filter chip & Play current view:** Clicking any genre filters All Tracks with a removable chip; header **Play** and **Mix** now play the active filtered and sorted view across playlists, All Tracks, Liked songs, and genres.
- **Collect a genre:** Save any genre as a snapshot playlist (in exact view order) or a live smart crate backed by canonical `GenreKey` rules that follow tag edits and new analysis.
- **Genre Galaxy sync:** Dashboard Genre Galaxy counts now come from `LibraryGenreIndex` so planet counts match the Library tree, and clicking a planet opens the filtered Library with that node highlighted.

### Spotify 2026 Compatibility (#508)
- **Zero-login public Spotify links:** Paste any public Spotify playlist or album URL in Import without signing in.
- **Own Spotify app setup & SDK upgrade:** Upgraded to `SpotifyAPI.Web 7.4.2` (Feb 2026 endpoints), added clear personal-mix / 100-track notices, a guided own-app setup card in both the Setup Wizard and **Settings → Connection**, and actionable 403 diagnostics.

### Search & Quality Matching (#543)
- **Honest, unified Search settings:** Removed placebo controls (`Ranking strategy`, `Fuzzy normalization`), unified file integrity and upscale checks into one **File checks** card, added a **Custom** quality profile chip, and standardized the verified-lossless floor (`≥ 400 kbps`).
- **Smarter matching:** Unicode-safe fuzzy matching for non-Latin titles, user excluded phrases applied as a candidate filter (never stripped from queries), and a shared `VersionTag` gate preferring Extended/Original mixes over Radio Edits.

### Library Polish (#550)
- **Tag cleanup rule pack:** Strips URLs, promo text, URL/HTML escapes, review-only mojibake, and garbage characters; normalizes mix parentheses (`Title - Extended Mix` → `Title (Extended Mix)`); copies remixers into the `Remixer` tag without altering titles; adds opt-in lowercase casing and a selection-level shared-text pass.
- **Bulk relocate missing folder:** **Library tools → Clean up → Relocate missing folder…** suggests the most common missing prefix, previews found/still-missing/path-locked counts, and re-points all three DB path columns without moving files on disk (with one-click undo via the relocation journal).
- **Daily playlist tools:** Track Inspector now shows **In playlists** (clickable links to open each playlist); playlist right-click adds **Compare with playlist…**, **Copy tracklist** (numbered plain text with BPM & key), and **CSV spreadsheet…** export.

### DJ Ecosystem Exports (#551 & #507)
- **Shared export projection & 24-key converter:** One target-neutral track projection and canonical `KeyNotation` table (Camelot ↔ Open Key ↔ musical ↔ Traktor int).
- **Traktor Pro NML:** Export standalone `.nml` playlists with cues, loops, beatgrid, BPM, and key (never touches live `collection.nml`).
- **VirtualDJ:** Export `.vdjfolder` playlists plus optional guarded `database.xml` cue/BPM/key merges (refuses while VirtualDJ is running, backs up first, stores `Scan Bpm` as `60 / BPM`).
- **Serato DJ crates:** Export binary `.crate` files grouped by drive (refuses while Serato DJ is running, backs up existing crates).
- **Opt-in Rekordbox direct cue write (experimental, #507):** Write ORBIT cues straight into Rekordbox's library (opt-in in Settings, backed up first, Rekordbox must be closed), plus a fix for selection XML export cues.
