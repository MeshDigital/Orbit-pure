## ORBIT 0.4.0

The biggest update since 0.3: Sets get their own page and one transition editor, beat grids you can
trust, a library clean-up toolkit, steadier downloads and much better genre detection for DnB, House and co.

### Sets & transitions
- **Sets page:** plan a gig as slot cards with role, energy target and notes per slot, plus a compatibility score between every pair. Drag to reorder; Ctrl+Z undoes.
- **Plan B** backups per slot, a **track pool** with key/BPM filters, and **Add to Set** from the Library's right-click menu.
- **Design transitions inside a set:** double-click the score between two slots. It's the same transition editor Flow Builder uses, with a rating and a "played it live" box. Transition Lab is gone.
- **Find a bridge track** between two slots that don't mix well.
- Flow Builder: drag the mix markers on either deck, per-deck zoom, every cue at hand; the incoming track snaps to cues and to spots where cues line up.

### Beat grids & Cue Forge
- BPM fixes (×2, ÷2, typed BPM) update the grid itself; a grid you edited or confirmed is never overwritten by re-analysis.
- Grid review chip, 1 ms slip, tap tempo, BPM from two downbeats and a metronome click.
- Cue Forge: "Back to" the page you came from; the first cue no longer plays from 0:00; Resume mix.

### Library
- **Library maintenance:** fix malformed tags, fill missing metadata, group unclassified tracks into style playlists, all previewed and undoable.
- **Find exact duplicates:** compares the audio itself, so re-tagged or renamed copies are found. Merges playlists, set slots and cues into the copy you keep; files go to the Recycle Bin only if you choose.

### Downloads
- A download whose audio you already have points to your existing file instead of adding a copy.
- Auto-download skips previews and cut-off files.
- Two tracks from the same user no longer share progress, and download speed is measured correctly, so fewer downloads are wrongly treated as stalled.

### Genre detection
- Genre now uses the fine-grained Discogs-400 style model and a rhythm & tempo check (4x4 kick vs backbeat vs half-time) instead of BPM ranges alone. On a 2,355-track test library, accuracy went from 16 % to 28 % with the first part alone, and House is detected at all for the first time. Tracks analysed before this release keep their old genre until they're re-analysed.

### Downloads for other platforms (experimental)
Windows is the supported platform. The Linux (`linux-x64`) and macOS Intel (`osx-x64`) archives are
**experimental**: they start, but audio playback and GPU analysis are Windows-only for now (details:
`DOCS/platform/MACOS_FEASIBILITY.md`). Apple Silicon isn't built yet. On macOS, unpack and run
`xattr -dr com.apple.quarantine ORBIT` first (the build isn't notarised).

Existing users see a "What's new" page on first start.
