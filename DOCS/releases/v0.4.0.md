## ORBIT 0.4.0

The biggest update since 0.3: Sets get their own page and one transition editor, full Library File Management (templates, Inbox/Direct staging, path protection, undoable reorganisation, in-place FLAC upgrades, and USB folder layouts), multi-source imports (YouTube, SoundCloud, M3U/TXT/JSON), album-mode search, MilkDrop visualisations, beat grids you can trust, and much better genre detection for DnB, House and co.

### Library file management & organisation
- **Naming templates & live preview:** 5 built-in presets, template validation, and a live 3-track preview in Settings.
- **Transactional file relocation & undo:** All moves and renames run through a single journaled relocation engine with rollback and stem-folder preservation.
- **Direct vs Inbox commit modes:** Download directly to your template path or stage in an Inbox folder, with optional automatic post-analysis re-filing (once BPM/Key are known) and a one-click **File to Library** action.
- **Path protection (Lock / Unlock):** Lock any track's file path from the Inspector or context menu so automated re-organisation never moves it.
- **Reorganise library wizard:** Preview Move / Unchanged / Blocked rows before applying as a single undoable batch, with optional empty-folder cleanup.
- **In-place quality upgrades (MP3 → FLAC):** Automatically swaps upgraded files in place, sends the old file to the Recycle Bin, and shifts cues & beat grids using cross-correlation decoder-offset estimation.
- **USB export folder layouts:** Export sets to USB sticks or folders organised by Key, BPM, Genre, or Playlist with FAT32-safe filenames and a live tree & size preview.

### Imports, search & visualiser
- **Multi-source playlist imports:** Zero-config YouTube playlist & Liked Videos import, public SoundCloud `/sets/` import, local `.m3u` / `.m3u8` / `.txt` / `.json` file import, and one-click Recent Imports re-sync.
- **Album-mode search:** Group search results into albums with alternates and one-click **Queue album**.
- **MilkDrop visualiser:** 12 built-in `.milk` presets plus automatic loading of custom presets from `<AppData>/ORBIT/Presets/MilkDrop`.

### Sets & transitions
- **Sets page:** plan a gig as slot cards with role, energy target and notes per slot, plus a compatibility score between every pair. Drag to reorder; Ctrl+Z undoes.
- **Plan B** backups per slot, a **track pool** with key/BPM filters, and **Add to Set** from the Library's right-click menu.
- **Design transitions inside a set:** double-click the score between two slots. It's the same transition editor Flow Builder uses, with a rating and a "played it live" box. Transition Lab is gone.
- **Find a bridge track** between two slots that don't mix well.
- **Export a set** to Rekordbox XML or a USB stick / folder (cues and beat grid included; transition notes in comments optional).
- **Edit the transition between any two Library tracks**: select two, right-click → Edit transition between these two.
- Flow Builder: drag the mix markers on either deck, per-deck zoom, every cue at hand; the incoming track snaps to cues and to spots where cues line up.

### Beat grids & Cue Forge
- BPM fixes (×2, ÷2, typed BPM) update the grid itself; a grid you edited or confirmed is never overwritten by re-analysis.
- Grid review chip, 1 ms slip, tap tempo, BPM from two downbeats and a metronome click.
- Cue Forge: "Back to" the page you came from; the first cue no longer plays from 0:00; Resume mix.

### Library maintenance & downloads
- **Library maintenance:** fix malformed tags, fill missing metadata, group unclassified tracks into style playlists, all previewed and undoable.
- **Find exact duplicates:** compares the audio itself, so re-tagged or renamed copies are found. Merges playlists, set slots and cues into the copy you keep; files go to the Recycle Bin only if you choose.
- **Steadier downloads & UI responsiveness:** Deduplicated audio pointing, preview/cutoff filtering, per-transfer progress tracking, lock-free peer blacklisting, and elimination of blocking waits & `Thread.Sleep` on hot paths.

### Genre detection & AI styles
- **Fixed a model input bug** that made AI styles, genres, moods and "similar tracks" close to noise. The EffNet model was fed a mis-scaled spectrogram (#270). On a 300-track test sample from a real DnB-heavy library, genre accuracy went from **26 % to 58 %**: DnB is recognised **89 %** of the time (was 0 %) and House 58 % (was 0 %).
- Genre now combines the detailed Discogs-400 style model with the Jamendo model, weights the drops over intros and outros, and checks the drums (a kick on every beat vs backbeat vs half-time) at both tempo octaves.
- **Confidence is honest now:** a guess is never shown as "confident" unless the data supports it (before, almost a third of tracks were confidently wrong).
- **Existing tracks keep their old genre/style until re-analysed.** Run **Library maintenance** and tick **"Analyse tracks with missing or outdated AI style"**.

### Platforms
- **Windows (`win-x64`)** — supported installer (`ORBIT-Setup-0.4.0-win-x64.exe`) and portable zip.
- **macOS (`osx-arm64` Apple Silicon & `osx-x64` Intel)** and **Linux (`linux-x64` AppImage & tarball)** — built and smoke-tested in CI (see `DOCS/platform/MACOS_FEASIBILITY.md`). On macOS, if unnotarised, run `xattr -dr com.apple.quarantine ORBIT.app` before first launch.

Existing users see a "What's new" page on first start.
