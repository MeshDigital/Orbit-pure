# ORBIT Improvement Plan — 2026-09-16 full-app audit

Full-codebase sweep via 5 parallel research agents (Library, Downloads/Search/Import,
Workstation/FlowBuilder/CueForge, Player/Queue/Social, Settings/Navigation/Dashboard/Analysis),
which fanned out into further sub-agents on the larger areas. 69 findings total, deduplicated
and prioritized below. This is a **live checklist** — check items off (`[ ]` → `[x]`) with a
one-line note as they're fixed, rather than filing a new doc per item, mirroring the convention
already established in `project_codebase_improvement_backlog` (see Claude memory).

**How to use this file:** work top-to-bottom within each tier. Tier 1 items are both the highest
user-visible impact *and* generally the cheapest to fix (wire a missing command, add a confirm
dialog) — do those first. Tier 2 is real, measurable performance work. Tier 3 is feature
gaps/dead code/UI polish — valuable but lower urgency.
